GeoServer CVE-2026-120705 / CVE-2026-129243 added to CISA KEV — exploitation seen, chain leads to unauthenticated RCE

CISA KEV on 27 Nov (due 30 Nov); escalation of the GeoServer row in the 26 Nov report.

8.6
Full details
1. Vulnerability details
  • CVE-2026-120705 (CVSS 8.6): unauthenticated file read and request forgery via WFS
  • CVE-2026-129243 (CVSS 8.8): incorrect authorization on OWS services
  • CISA KEV 27 Nov, due 30 Nov
  • In-the-wild probing seen by watchTowr on 25 Nov
  • Advisories 24 Nov
  • Patches released Oct–Nov
2. Issue
  • One flaw lets anyone read files on the server and make it fetch URLs
  • The other lets anyone call OGC service operations that security rules should protect
3. How it is exploited
  • Unauthenticated requests to WFS / OWS endpoints read configuration files, including the remember-me signing key, and reach protected operations
  • Combined with the related flaws (CVE-2026-129245 hard-coded key, CVE-2026-129242 JDBC deserialization) this can give remote code execution
4. Affected configurations
  • GeoServer before 2.27.7, 2.28.6 and 3.0.2 (gs-wfs-core, gs-ows, gs-main; gt-metadata before 33.7 / 34.6 / 35.2)
5. Impact
  • Credential and configuration theft, access to protected map services, possible full server takeover

Recommendations

  • Update to GeoServer 2.27.7, 2.28.6 or 3.0.2 now.
  • If you cannot patch, restrict GeoServer to trusted networks.
  • Audit exposed servers for leaked credentials, new stored queries and code running on the host.
  • Rotate secrets on any server that was exposed — changing the key in security/config.xml alone does not help.

Microsoft Store app "Setup Assistant" delivered the PowerShell-based Vinci RAT

Malware shipped through the official Microsoft Store with a Microsoft-signed installer.

Full details
1. Details
  • eSentire research
  • Electron app "Setup Assistant" by ETPS Ltd, first released 1 Jun 2026
  • Reported to Microsoft 10 Nov
  • App no longer available
  • Not attributed
2. Issue
  • A fake download site for a screenshot tool sent users to a Store app that downloads and runs a remote access trojan
3. How it is exploited
  • Search redirect
  • Fake sniping-tool site
  • Microsoft-signed installer
  • Setup Assistant pulls obfuscated JavaScript / PowerShell
  • Stager disables AMSI, adds a scheduled task every 10 minutes and installs Vinci RAT (T1059.001, T1053.005)
  • Lookalike sites also spoof Teams and Roblox downloads
4. Affected
  • Windows users who installed "Setup Assistant" from the Microsoft Store or the lookalike sites
5. Impact
  • Remote shell, file delivery and execution of shellcode / DLL / EXE
  • Inventory of security tools

Recommendations

  • Search endpoints for "Setup Assistant" by ETPS Ltd and remove it.
  • Hunt for PowerShell scheduled tasks that run every 10 minutes.
  • Block the indicators below.
  • Allow only approved Microsoft Store apps on managed devices.

Suspected Vietnam-linked WeaveLotus spies on Southeast Asian governments and military over the South China Sea

Confirmed intrusions at government, military and legislative bodies using old, public flaws and default passwords.

EPSS 99.8% · 100% pct
Full details
1. Details
  • SOCRadar research
  • WeaveLotus (RedOps)
  • 5 confirmed intrusions in Thailand and the Philippines plus reconnaissance of Indonesia
  • Aug–Sep 2026
  • State sponsorship not confirmed
2. Issue
  • An espionage cluster breaks into exposed public-facing apps to steal government data tied to South China Sea interests
3. How it is exploited
  • Exploits GeoServer CVE-2024-36401 and osTicket CVE-2021-42235, default JasperReports admin passwords, Laravel debug mode and root SSH on Keycloak 3.4 (T1190, T1078)
  • Reverse SSH tunnels and SOCKS proxies, lateral movement, password spraying, offline cracking of Keycloak hashes (T1572, T1110)
4. Affected
  • Government, military and legislative organisations in Thailand, the Philippines and Indonesia
5. Impact
  • 349,782 records from a Thai government system, 1,502 directory records and 5,000 archives from a Thai legislative body, and military CMS data

Recommendations

  • Patch GeoServer CVE-2024-36401 and osTicket CVE-2021-42235.
  • Remove default credentials and turn off Laravel debug mode in production.
  • Upgrade end-of-life Keycloak and block root SSH.
  • Block the indicator below.
