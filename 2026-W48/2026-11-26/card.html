Drupal CVE-2026-136716 — new installer site-takeover flaw exploited after the Fail2Install fix

Exploited in the wild; the earlier Fail2Install patch left some sites still open to takeover.

Full details
1. Vulnerability details
CVE-2026-136716 · CWE-754 · Drupal SA-CORE-2026-019 · exploited in the wild · not in KEV yet · ~31,500 internet-facing sites on branches hit by Fail2Install (StepSecurity)
2. Issue
After the Fail2Install fix (CVE-2026-132165), sites left in an unusual or incomplete install state — including production sites — can still be taken over. The state isn't visible in the admin UI.
3. How it is exploited
Attacker reaches a remotely accessible installer (install.php) on an affected site and takes over the site; already-compromised sites may no longer look vulnerable.
4. Affected configurations
Drupal 10.6, 11.3 and 11.4 before 10.6.23 / 11.3.23 / 11.4.14; no fix for EOL 11.0–11.2 and 10.5 and below. Sites that already secured the installer are not affected.
5. Impact
Full site takeover.

Recommendations

  • Update to 11.4.14 / 11.3.23 / 10.6.23, then run update.php.
  • Block or remove install.php on every site.
  • Check logs for changes to or by user 1; confirm user 1's email and reset its password.
  • Move off EOL branches.

Mitel MiCollab AWV — five flaws exploited (due 28 Nov)

Unauthenticated command execution on a collaboration server, exploited; KEV with a 3-day deadline.

9.8
Full details
1. Vulnerability details
CVSS 9.8 (CVE-2026-133323, 10.0 per MITRE; CVE-2026-133303) plus CVE-2026-133275 / -133311 / -133324 · KEV 25 Nov, due 28 Nov (-133311 due 9 Dec) · Mitel MISA-2026-0012
2. Issue
The AWV (audio/web conferencing) component has unauthenticated command injection, XML injection, file upload, authentication bypass and information-disclosure flaws.

Unauthenticated requests to an exposed AWV component lead to arbitrary command execution; no public details yet on how attackers use them.
4. Affected configurations
MiCollab 10.3 (10.3.0.18) and earlier.

  • Until then, block external access to the AWV component.
  • Review AWV logs for uploads and unexpected commands.

Danfoss AK-SM 800A refrigeration controllers — 3 flaws in CISA KEV plus a new unpatched CVSS 9.8 bug

Controllers used in attacks that switched off cooling in European supermarkets; one critical flaw has no patch yet.

9.8
Full details
1. Vulnerability details
KEV 25 Nov: CVE-2023-25915 (8.8; 9.9 per DIVD) and CVE-2023-25914 (8.8), due 28 Nov; CVE-2025-41450 (7.5), due 9 Dec · unpatched CVE-2026-129713 (CVSS 9.8, CISA ICSA-26-328-03, Danfoss DSA-2026-12-01)
2. Issue
KEV flaws allow command execution, file reads and authentication bypass; the new bug is a stack buffer overflow in an unauthenticated CGI handler.
3. How it is exploited
Attackers reach internet-exposed controllers and change refrigeration settings; France attributed October attacks to the IRGC-linked Shahid Kaveh unit (aka Cyber Aveng3rs). On 2 Nov at least 115 stores in seven countries had cooling shut down or changed.
4. Affected configurations
AK-SM 8xxA series (820A, 850A, 880A); CVE-2026-129713 affects 5.4.0 and earlier, with a fix due in 5.5.x. Supermarkets and food retailers.
5. Impact
Remote control of refrigeration — spoiled stock and safety risk; possible code execution on the controller.

Recommendations

  • Take controllers off the internet; allow remote access only through an up-to-date VPN.
  • Enable Strict mode and use strong passwords.
  • Isolate control networks from business IT.
  • Install 5.5.x as soon as Danfoss releases it.

PHP2Shell in bundled PHP now exploited on Palo Alto and Check Point firewalls; fixes missing for several appliance vendors

Most exploited appliance flaws this month came from bundled third-party components, and some vendors have no fix yet.

Full details
1. Details
Eclypsium InfraTrust Pulse (15 Oct–19 Nov): 373 advisories from 23 vendors, 38 KEV flaws — 33 in bundled components (PHP, Node.js, OpenSSH) · PHP2Shell CVE-2026-109618 / -109619
2. Issue
Network appliances ship their own copies of PHP and other components, so a PHP flaw becomes an appliance flaw until each vendor ships an update.
3. How it is exploited
PHP2Shell is chained for root on firewalls (see the PAN-OS Fragnesia item on 25 Nov); Check Point reported wiper malware on VMware ESXi hosts.
4. Affected
As of 20 Nov, fixes were partial or not released for Fortinet, Juniper, Lenovo, HPE, Netgear, HP and Siemens. Also flagged: Check Point CVE-2026-123039, Arista VeloCloud CVE-2026-114625, Cisco ASA/FTD CVE-2026-76418, SonicWall CVE-2026-19868.
5. Impact
Root on edge appliances; destructive follow-on attacks.

Recommendations

  • List appliances that bundle PHP and track each vendor's PHP2Shell fix.
  • Keep management interfaces off the internet.
  • Patch the KEV-listed appliance flaws named above first.
